1

Se connecter

À l'ouverture, cliquez sur le profil 👤 Usager, puis :

  1. Sélectionnez votre site (Audi, SEAT, SKODA ou VW).
  2. Saisissez votre e-mail @geauto.fr et votre mot de passe, puis Se connecter.
Le KVPS et le nom du site se remplissent automatiquement selon le site choisi. Vous n'avez rien à ressaisir.

Mot de passe oublié

Sur l'écran de connexion, cliquez sur 🔑 Mot de passe oublié ? (après avoir saisi votre e-mail) : une demande est automatiquement envoyée à la TeamGarantie, qui vous attribuera un nouveau mot de passe. Vous pouvez aussi la contacter directement à teamgarantie@geauto.fr ou par téléphone/Teams.

Une fois connecté avec le mot de passe reçu, vous pouvez le personnaliser à tout moment : bouton 🔑 Mot de passe en haut à droite de l'application.

Pas encore de compte ? Contactez teamgarantie@geauto.fr.

2

Créer une demande KULANZ

Une fois connecté, l'onglet 📝 Formulaire est actif et le type Demande KULANZ est sélectionné par défaut.

① Identification du véhicule

  • Numéro de châssis — 17 caractères. Il est contrôlé en direct (les lettres I, O, Q sont interdites). Un ✔ vert confirme un châssis valide.
  • Kilométrage et N° d'OR (6 chiffres).
  • Date de l'OR, nom du demandeur et votre e-mail (utilisé par la TeamGarantie pour vous recontacter si besoin).
Si un véhicule a déjà fait l'objet d'une demande, commencez à taper le châssis : une suggestion apparaît et pré-remplit kilométrage, date, demandeur, e-mail…

② Nature du dommage

  • Plainte du client — décrivez le symptôme signalé.
  • Catégorie — choisissez un domaine (Motopropulseur, Transmission, Trains roulants, Carrosserie, Chauffage/Clim, Équip. électrique) ou « Saisie libre ».
  • Désignation → Code dommage → Code avarie — voir la section suivante (la rubrique est déduite automatiquement).

③ Vérifications KULANZ

Les questions s'adaptent automatiquement à la marque du site (VW, Audi, SEAT, SKODA). Répondez par Oui / Non. Si une réponse rend le dossier non éligible (NOK), une alerte rouge explique pourquoi et rappelle la règle constructeur correspondante.

Exemples de blocages : code tuning présent dans SAGA, pièce d'usure, ou préconisations d'entretien non respectées.
3

Choisir les codes (cascade)

Les champs fonctionnent en cascade : chaque choix affine le suivant.

  1. Catégorie — choisissez la famille concernée (Motopropulseur, Transmission, Trains roulants…).
  2. Désignation pièce — cliquez sur le champ, tapez quelques lettres, sélectionnez la pièce.
  3. Code dommage — proposé automatiquement à partir de la désignation. S'il n'existe qu'un seul code, il est sélectionné pour vous.
  4. Code avarie — décrit le type de défaut (mécanique, corrosion, étanchéité…).
La rubrique est déterminée automatiquement à partir de la pièce ou du code : vous n'avez plus à la saisir. Elle reste enregistrée dans la demande, l'e-mail et le PDF.
Chaque liste possède une recherche (par code ou libellé) et une saisie manuelle si le code voulu ne figure pas dans la liste. Le bouton ✕ Effacer réinitialise un champ.
4

Faire une demande CCR

Basculez sur Demande CCR en haut du formulaire.

Une demande KULANZ doit avoir été effectuée avant toute demande CCR.

Gagner du temps

Si vous venez de remplir une KULANZ, cliquez sur Copier les données depuis Kulanz : châssis, OR, plainte, codes… sont repris automatiquement dans la CCR.

Pièces à fournir (section 4)

  • Devis – sans forfait, sans diagnostic.
  • Plan d'entretien numérique ELSA disponible ? (Oui / Non) — obligatoire. Si vous répondez Non, un bloc apparaît pour cocher les factures d'entretien (réseau / hors réseau).
  • IQ n° — obligatoire, exactement 9 chiffres.
  • Feuille Commentaire Technicien avec diagnostic.
L'envoi est bloqué tant que la réponse ELSA n'est pas donnée et que le n° IQ ne fait pas 9 chiffres. La case d'engagement reste à cocher avant l'envoi.
5

Envoyer la demande

Quand le formulaire est complet, cliquez sur Envoyer la demande. L'application vérifie les champs obligatoires, puis affiche un résumé de la demande : relisez-le, puis cliquez sur « Confirmer l'envoi » — ou sur « Modifier » pour revenir au formulaire (rien n'est envoyé tant que vous n'avez pas confirmé). Un écran « Demande envoyée ! » s'affiche ensuite : vous savez ainsi que la demande est bien partie.

Pour une Kulanz, l'écran « Demande envoyée ! » propose le bouton « Envoyer l'e-mail de confirmation » : un e-mail pré-rempli s'ouvre dans votre messagerie, adressé à vous avec la TeamGarantie en copie, avec le récapitulatif de la demande. Si la demande comporte des points d'attention (par exemple « Dernier entretien manquant »), ils apparaissent dans le résumé et dans le mail.
Si des champs manquent, un seul message récapitule tout ce qu'il reste à corriger, et les champs concernés sont surlignés en rouge (la page défile jusqu'au premier). Plus besoin de cliquer plusieurs fois.
Votre saisie est sauvegardée automatiquement : l'indication « ✓ Enregistré » apparaît près de la barre de progression. Si vous tentez de fermer l'onglet avec une demande non envoyée, le navigateur vous prévient pour éviter toute perte.

Pour une demande CCR : joindre les documents

Après l'envoi d'une CCR, un e-mail pré-rempli s'ouvre dans votre messagerie : il est adressé à l'usager qui a créé la demande, avec la TeamGarantie en copie (CC). Avant de cliquer sur « Envoyer » dans votre messagerie, joignez les documents justificatifs de votre dossier, par exemple :

  • l'Ordre de Réparation (OR) ;
  • le devis au taux garantie ;
  • les factures d'entretien (réseau et/ou hors réseau) ;
  • le commentaire technicien / la feuille de diagnostic ;
  • le plan d'entretien ELSA, l'IQ, les photos/vidéos avec châssis, etc.
Important : ces documents sont vos propres fichiers (PDF, photos…) à récupérer depuis vos outils habituels (SAGA, ELSA, scanner…). Ce ne sont pas le « PDF récapitulatif » que l'application peut générer : ce dernier n'est qu'un résumé de la saisie, il ne remplace pas les justificatifs.

Le bouton « Enregistrer en PDF »

Le bouton Enregistrer en PDF crée un simple récapitulatif de ce que vous avez saisi, pratique pour archiver ou relire. Il ne contient aucun justificatif et n'est pas obligatoire.

Le sujet de l'e-mail CCR est rempli automatiquement (Demande CCR – KVPS – Site – Châssis – Demandeur), ce qui aide la TeamGarantie à traiter votre dossier. La TeamGarantie est systématiquement mise en copie (CC) des e-mails préparés par l'application.
Si un champ obligatoire manque (châssis, OR, plainte, désignation, code dommage, code avarie, nom, e-mail), un message vous l'indique et l'envoi est bloqué tant qu'il n'est pas corrigé.
6

Ouvrir le mail automatiquement (pré-rempli)

Pour une demande CCR, l'application ouvre un e-mail déjà pré-rempli vers teamgarantie@geauto.fr (destinataire, sujet, corps). Pour que cet e-mail s'ouvre tout seul dans Outlook, voici la configuration à faire une seule fois.

Outlook classique (application installée sur le PC)

  1. Ouvrez Paramètres Windows (touche Windows + I).
  2. Allez dans Applications → Applications par défaut.
  3. Faites défiler jusqu'à « E-mail » (ou cherchez « E-mail » dans la barre de recherche).
  4. Cliquez sur l'application affichée, puis sélectionnez Outlook.
Après ça, un clic sur « Envoyer » d'une CCR ouvre directement un nouveau message Outlook, pré-rempli. Il ne reste qu'à joindre vos documents et envoyer.

Outlook web (outlook.office.com, dans le navigateur)

Dans ce cas, c'est le navigateur (Edge ou Chrome) qui doit être autorisé à ouvrir les liens e-mail avec Outlook web.

  1. Connectez-vous à Outlook web (outlook.office.com) dans Edge ou Chrome.
  2. Cliquez une fois sur « Envoyer » dans l'application : une petite icône (en forme de losange ou de fenêtre) apparaît à droite de la barre d'adresse.
  3. Cliquez dessus, choisissez Autoriser Outlook à ouvrir les liens e-mail, puis Terminé.
Réglage manuel si l'icône n'apparaît pas — Edge : menu … → Paramètres → Cookies et autorisations de site → Gestionnaires de protocole → autoriser les liens « mailto » pour Outlook. Chrome : menu ⋮ → Paramètres → Confidentialité et sécurité → Paramètres des sites → Gestionnaires de protocole, puis autorisez Outlook.
Si l'e-mail ne s'ouvre toujours pas : copiez l'adresse teamgarantie@geauto.fr, créez un e-mail manuellement dans Outlook et joignez vos documents. La demande est de toute façon déjà enregistrée dans l'application.
7

Suivre & traiter les demandes

Une fois connecté, trois onglets sont disponibles en haut : 📝 Formulaire, 📥 Demandes et 📋 Historique.

📥 Demandes (à traiter)

Cet onglet liste les demandes En attente et Complément requis. Le nombre en attente s'affiche directement sur l'onglet (ex. « 📥 Demandes (3) »).

Côté TeamGarantie, deux actions distinctes :

  • Bouton Valider → ouvre la fenêtre de validation pour traiter la demande (choisir le statut, le commentaire, la prise en charge). Un e-mail récapitulatif est préparé à la validation.
  • Clic sur la ligne (ailleurs que sur le bouton) → propose de modifier la demande : le formulaire s'ouvre pré-rempli pour corriger les champs, et l'enregistrement se fait sans envoyer d'e-mail. Idéal pour corriger une erreur de saisie.

Pour un usager, un clic rouvre simplement sa demande pour la consulter ou la corriger.

La fenêtre de validation affiche toutes les infos utiles pour décider : kilométrage, code dommage, code avarie, et l'ensemble des vérifications KULANZ renseignées par le demandeur (TPI, OPTEVEN, tuning, pièce d'usure, entretien…), avec les réponses bloquantes signalées en rouge.

📋 Historique (traité)

Cet onglet n'affiche que les demandes déjà traitées. Le bouton d'une demande traitée affiche « ✓ Validée ». Cliquer sur une demande la rouvre pré-remplie pour créer rapidement une nouvelle demande similaire (même client, même réclamation).

Outils communs aux deux onglets

  • Onglets 🔧 Kulanz / 📋 CCR : séparent les deux types, chacun avec ses statistiques.
  • Recherche : par châssis, n° OR, conseiller ou code dommage.
  • Tri : cliquez sur les en-têtes Date, Site, N° OR ou Statut.
  • Export CSV (TeamGarantie) : exporte la liste filtrée, ouvrable dans Excel.
La barre de progression en bas du formulaire indique en temps réel combien de champs obligatoires sont remplis (et passe au vert à 100 %).

Les statuts

🟡 En attente ✅ Traitée ❌ Traitée sans participation 🔄 Complément requis
StatutSignification
En attenteDemande reçue, en cours d'examen par TeamGarantie.
TraitéeAccordée — la prise en charge commerciale est renseignée.
Traitée sans participationExaminée mais sans participation accordée.
Complément requisUn document ou une information manque ; à compléter.
Dans la liste, le bouton d'action reflète le statut : Valider (en attente), ✓ Validée (traitée), À compléter (complément requis).
9

Questions fréquentes

J'ai oublié mon mot de passe, comment le réinitialiser ?
Sur l'écran de connexion, saisissez votre e-mail puis cliquez sur 🔑 Mot de passe oublié ? : une demande part automatiquement vers la TeamGarantie, qui vous attribuera un nouveau mot de passe. Une fois connecté, vous pourrez le changer vous-même via le bouton 🔑 Mot de passe en haut de l'application.
Le menu de code avarie / dommage ne s'ouvre pas entièrement.
Videz le cache de votre navigateur (Ctrl + Maj + R) pour charger la dernière version. Le menu doit s'afficher complet, par-dessus la section suivante.
L'e-mail CCR ne s'ouvre pas tout seul après l'envoi.
Votre messagerie par défaut n'est probablement pas configurée. Voir la section « Ouvrir le mail automatiquement ». En dernier recours, écrivez manuellement à teamgarantie@geauto.fr en joignant vos documents : la demande est déjà enregistrée dans l'application.
Quels documents dois-je joindre à une CCR ?
Vos justificatifs : OR, devis au taux garantie, factures d'entretien, commentaire technicien, plan ELSA, IQ, photos avec châssis… Ce ne sont pas le « PDF récapitulatif » de l'application, mais vos propres fichiers.
Mon e-mail @geauto.fr est refusé à la connexion.
Vérifiez l'orthographe exacte de votre adresse. En cas d'oubli du mot de passe, contactez la TeamGarantie qui le réinitialisera. Si le problème persiste, écrivez à teamgarantie@geauto.fr.
La cascade ne propose pas le bon code.
Utilisez la recherche par libellé, ou la saisie manuelle en bas de chaque liste.
Comment retrouver / rouvrir une demande déjà créée ?
Dans l'onglet 📋 Historique, cliquez sur la ligne de la demande. Si elle est encore « En attente », vous pouvez la modifier ; si elle est déjà traitée, elle s'ouvre pré-remplie pour créer rapidement une nouvelle demande similaire.
Une question non couverte ici ? Écrivez à teamgarantie@geauto.fr.
